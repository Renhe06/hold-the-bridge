# 《跃》关卡设计（重做版）

> 上一版把七波做成了"七个障碍关卡"——那是前四关的语法。
> 这首歌不是七个关卡，是**一条下坠的曲线**。

---

## 一、歌词的骨架：不是七段，是四层情绪下沉

| 段落 | 原句 | 情绪 | 世界状态 |
|---|---|---|---|
| 1 | 海洋静谧依旧 / 月光无声弹奏 / 鱼群翩翩舞动 | **美** | 完好 |
| 2 | 乳白色蜉蝣，它竟不会腐朽 / 总是陪我徜徉 | **孤独** | 多了不该有的东西 |
| 3 | 是那沉没的舰 / 灯塔忽明忽灭 / 又在鱼缸里面 | **困惑** | 人类留下的痕迹 |
| 4 | 血引来了海鸥 / 漏网之后留下了伤口 | **疼** | 开始被猎杀 |
| 5 | 唱贪婪的盛宴 / 若交出海底项链 | **交易** | 掠夺者现身 |
| 6 | 看冰山在崩裂 / 看沥青在蔓延 / 曾是我纯洁的家园 | **毁灭** | 家园没了 |
| 7 | 唱给这世界在慢慢下潜 / 我听见你无声的永别 | **死** | 一切沉没 |
| 8 | 鱼儿又跃出海面 / 珊瑚在海底蜿蜒 / 最美丽的花园 | **幻象** | 临终回放 |

**关键**：第 8 段不是"胜利"，是**死前的幻视**。
所以这一关的结局不是"通关"，是"你看完了"。

---

## 二、核心结构：一局 = 一次下潜到底

不再是七波，是**一条从海面到深渊的连续下潜**。

- 玩家从海面出发，一路往下
- 氧气只够潜到某个深度，**必须上浮换气**
- 每次上浮再下潜，都会比上次更深一点
- 每深一层，看到的歌词就往下一段走

**波次取消，改叫「层」。** 玩家不是在闯关，是在往下走，而且回不去上一层的世界了。

```
深度 0.00 ─ 海面      月亮 / 满星 / 远船            第 1 段的开头
深度 0.15 ─ 浅水      藏蓝丝绸 / 鱼群 / 洋流        第 1 段
深度 0.30 ─ 塑料层    乳白色蜉蝣 / 渐暖的洋流       第 2 段
深度 0.45 ─ 残骸层    沉没的舰 / 灯塔               第 3 段
深度 0.60 ─ 猎杀层    血 / 海鸥 / 鱼钩 / 渔网       第 4 段
深度 0.75 ─ 掠夺层    渔船 / 声呐 / 海底项链        第 5 段
深度 0.88 ─ 废墟层    冰山 / 沥青 / 垃圾 / 混浊     第 6 段
深度 1.00 ─ 深渊      没有光 / 同类在下面           第 7 段
   └───────── 死亡瞬间：幻象花园 ──────── 第 8 段
```

---

## 三、每一层：看什么、听什么、做什么

### 0.15 浅水 —— 美
- **看**：藏蓝丝绸的水体、光柱、鱼群绕着你转、洋流把水草推弯
- **听**：海浪很远、鲸歌很清、水声干净
- **做**：游，第一次听见同类的歌（从远处来）
- **这一层要给的**：让玩家想待在这里。后面才有得毁。

### 0.30 塑料层 —— 孤独
- **看**：乳白色的塑料袋漂着，和鱼群混在一起，分不清哪个是活的
- **听**：塑料袋擦过身体的声音（沙沙），比鲸歌更频繁
- **做**：穿过去。它不会腐朽，也不会让路
- **细节**：这一层的鱼群数量是第 1 层的 80%，但塑料袋有 12 个

### 0.45 残骸层 —— 人类的痕迹
- **看**：沉船横在海底，锈水往下淌；灯塔在远处忽明忽灭
- **听**：金属呻吟（船体在压力下变形）、灯塔的机械转动
- **做**：绕着沉船走。它不是障碍，是墓碑
- **细节**：**这艘船在下篇会再出现一次**（搁浅在城市广场上）

### 0.60 猎杀层 —— 疼
- **看**：血雾在自己身后散开（酒红色），海鸥从上面扎下来；鱼钩像雨一样垂着
- **听**：海鸥叫、鱼钩碰水的叮、鲸自己的心跳
- **做**：躲。第一次受伤不掉血，掉的是"暴露度"
- **这一层的转折**：玩家第一次意识到"我不是在看风景"

### 0.75 掠夺层 —— 交易
- **看**：头顶有一整支船队，灯火通明，拖网在水里像一道墙；声呐一圈圈扫下来
- **听**：船引擎（低频、持续）、声呐 ping、绞车收网
- **做**：献祭。交出海底项链，换一次满氧
- **这一层要给的**：让玩家以为"还能谈"

### 0.88 废墟层 —— 毁灭
- **看**：冰山在远处崩，黑色沥青从上面漫下来，垃圾堆成山，水变浑
- **听**：冰裂的巨响（很远）、引擎、实验设备的电流声
- **做**：什么都做不了，只能往下
- **细节**：这一层开始，鱼群为 0

### 1.00 深渊 —— 死
- **看**：全黑，只有一个同类的轮廓，在更深处
- **听**：只剩自己的心跳和一声很远的歌
- **做**：继续往下（氧气已经不够回来了）

### 死亡瞬间 —— 幻象
- **看**：画面突然亮起来——珊瑚重新长出颜色，鱼群回来了，阳光从水面照下来
- **听**：所有声音同时回来，很满，然后一个个消失
- **做**：什么都不做
- **这一层要给的**：让玩家知道"刚才那一切本来是可以留住的"

## 四、对比：同一个位置，看三次

这是整关最重要的一手法，比加一百个元素都有效。

| | 第一次（浅） | 第二次（中） | 第三次（深） |
|---|---|---|---|
| 珊瑚 | 有颜色，会随水流摆 | 白化，一动不动 | 碎成一地白骨 |
| 鱼群 | 22 条，绕着你游 | 8 条，躲着你 | 0 条 |
| 水色 | 藏蓝，透光 | 灰蓝，发浑 | 黑，只有手电/声呐能照到 |
| 声音 | 鲸歌、水声 | 引擎、声呐 | 死寂 + 心跳 |
| 光 | 月光、光柱 | 船的探照灯 | 没有 |

玩家第三次经过同一块礁石时，会认出来。这比任何台词都狠。

---

## 五、玩法：三个动作，一个数字

- **游**：拖动
- **唱**：长按。让同类回应，也会暴露自己
- **跃**：上浮到水面。换气，也是唯一能看见"上面"的时候
- **氧气**：唯一的数字，也是唯一的失败条件

**没有**：血条、分数、连击、升级、杀死任何东西。

失败 = 氧气耗尽。不是"你死了"，是"你没能回去"。

---

## 六、结局

不是"通关"，是**看完**。

氧气归零 → 世界继续变暗 → 幻象花园亮起 7 秒 → 全部熄灭 → 黑屏上一行：
> 还是说　有人类就无解

没有"重试"按钮，只有"再看一次"。

## 七、当前代码与这份设计的差距

| 项 | 状态 |
|---|---|
| 双界（海面/深渊） | ✅ 已做 |
| 氧气唯一数字 | ✅ 已做 |
| 发声 = 暴露 | ✅ 已做 |
| 沉船 / 灯塔 / 船队 / 冰山 / 城市 | ✅ 画了，但船型难看 |
| 洋流 | ⚠️ 有推力，看不出方向 |
| 八层深度 | ❌ 现在是七波，割裂 |
| 同一位置三次对比 | ❌ 完全没做 |
| 珊瑚 | ❌ 没做 |
| 混浊 / 垃圾堆 | ❌ 只做了油污 |
| 幻象花园 | ❌ 没做——这是结尾最重要的一场戏 |
| 声音层次（干净→嘈杂→死寂） | ❌ 现在是均匀的 |
| 真实录音 | ⚠️ 只接了两个（海浪海鸥、破水） |

## 八、建议的实现顺序

1. **把七波改成八层，一局到底**（结构，半天）
2. **同一位置三次对比**（珊瑚 + 鱼群 + 水色，一天）
3. **幻象花园**（结尾，一天）
4. 船型重画、洋流强化、垃圾堆、混浊（一天）
5. 声音分层（半天）

前两步做完，"不好玩/看不懂"会解决一半——因为玩家有了一条**明确的下坠路线**，而不是被扔进七个看不懂的小房间。
