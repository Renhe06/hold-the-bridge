守 桥

丧尸围城 · 手机网页小游戏 · 使用说明

开 始 玩

1装到桌面上（一次就好）

  1. iPhone 用 Safari 打开游戏；安卓用 Chrome 打开。
    从微信点进来的话，先点右上角 ··· → 在 Safari 中打开（安卓选「在浏览器打开」）。微信内置浏览器装不了桌面图标。
  2. iPhone：点屏幕底部的 分享 ⬆️ → 往下滑找到 添加到主屏幕 → 添加。
    安卓：点右上角 ⋮ → 添加到主屏幕。
  3. 回到桌面，点新出现的「守桥」图标——全屏打开、没有地址栏，跟装的 App 一模一样。
为什么要装到桌面：一是全屏更舒服、不会误触地址栏；二是只有装到桌面的版本才能长期离线玩（见下一条）。

2离线也能玩

  • 第一次必须联网（就几秒钟，这一步是把游戏存进手机里）。
  • 存好之后，断网、飞行模式、地铁里、没信号都能玩，一点不卡——它是一个纯本地的游戏，不联网也不会去取任何东西。
  • 想确认一下：打开飞行模式，点桌面「守桥」图标，还能进游戏就说明存好了。
  • 最高分存在你手机本地，断网玩也照样记录；但换手机不会同步。
别去 iPhone「设置 → Safari → 清除历史记录与网站数据」——那会把存好的游戏一起清掉，需要重新联网打开一次。手机存储特别紧张时系统也可能回收，重新联网打开一次即可恢复。

3以后更新怎么办

  • 你什么都不用做。我这边改完一推，你下次打开就是最新版——游戏是「联网时先取最新版、断网时才用手机里存的旧版」。
  • 如果感觉还是旧版：在浏览器里下拉刷新一下；已经从桌面图标打开的，从后台划掉再点开。
  • 不用重新「添加到主屏幕」，图标一直有效。
  • 更新不会清掉你的最高分。

430 秒学会玩

  • 一根手指按住屏幕任意位置拖：左右 = 走位，往上拖 = 前进（越靠前打出的伤害越高，最多 +19.6%）。
  • 自动开火，不用瞄准，你只管走位。
  • 丧尸挤到桥头后下蹲发光 = 要扑你，这时候闪开。
  • 每清掉一波，桥面左右滑来两块奖励门：你人站在哪半边，就吃哪一块（上面写着 +1 子弹伤害、×1.18 射速、−35% 敌人速度 这类）。
  • 连续击杀攒 连杀，分数越滚越高；被咬一口连杀立刻清零。
  • 击杀充能，满了点右下角 「空袭」：轰炸机从夜空掠过，一串导弹从天而降，把整条桥犁一遍。
  • 每 3 波会来一个词条（狂暴 / 厚皮 / 丧尸潮 / 血月浓雾 / 疾行者），横幅会报出来。
  • 提防三种特殊丧尸：远处吐酸的吐酸者、举盾减伤的铁盾兵、死后分裂成两只的分裂者。
  • 每 5 波是 BOSS 波：尸潮首领先推来一大片一枪一个的人海给你割草，它自己体型巨大、走得慢、够不到你，但会不停从身前往外放小崽子 —— 它的血条挂在屏幕顶部。
  • 打完第 15 波就通关第一关：按这局得分结算金币（结算面板上会写这局赚了多少、总共多少）。主界面上的角色 / 武器 / 商店 / 关卡四个入口现在是占位，功能以后再加。

?打不开 / 没声音

  • 一直白屏或转圈：第一次打开需要联网，换个网络再试；或者加桌面图标后从图标打开。
  • 没有声音：先随便点一下屏幕（浏览器规定必须用户先碰一下才允许出声）；再检查手机侧边的静音拨片；左上角喇叭图标可以开关声音。
  • 卡住了：从后台划掉重新打开，最高分还在。
